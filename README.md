# 暴走鱼市

原创横屏动作钓鱼微信小游戏 MVP。玩家抛竿锁定目标，通过弱点击破、空中命中、连击和极限收杆积累“精彩度”，精彩度直接提高渔获售价。

## 当前交付

- Cocos Creator 3.8 TypeScript 项目骨架
- 可独立测试的战斗、精彩度、经济、升级、存档与反作弊领域层
- 22种原创鱼、3件五级工具、5座岛和3个三阶段首领的数据配置
- Cocos运行时控制器、微信平台适配、云存档和好友榜接口
- 微信云函数：读档、存档、删档、提交成绩与远程配置
- 包体、性能、合规、提审及20–50人测试材料

## 开发环境

1. 安装 Cocos Creator 3.8.x，用编辑器打开本目录。
2. 首次打开后由编辑器生成 `library/`、`temp/` 和资源 `.meta` 文件。
3. 运行时唯一主路径为 `RuntimeHome → RuntimePrototype`；编辑器场景装配步骤见 `docs/SCENE_SETUP.md`。
4. 构建平台选择“微信小游戏”，AppID 在本地构建面板填写，不提交仓库。
5. 将 `cloudfunctions/` 目录配置为微信云开发云函数根目录并逐个部署。

本机未安装 Cocos Creator 时，仍可验证纯逻辑：

```bash
npm install
npm run validate
npm run simulate
```

`npm run playtest:report`会读取`playtest/participants.csv`；真实有效行不足20条时主动失败，防止把自动模拟冒充人类体验测试。

## 试玩流程

新存档自动进入泡沫湾首局，依次引导抛竿、弱点击破、捡起和入箱；教学完成状态与本局收益一起在统一结算中保存。五岛基础线依次进入棱光礁、风眼环礁、雾钟群岛和熔潮火山，模拟中完整基础解锁中位约3–5小时。

阶段2加入本地每日订单、统一种子的周挑战和Boss后无尽潮。每日奖励仅为金币或外观碎片；周挑战标记付费/广告加成局为不可上榜；无尽潮每3分钟一轮，可随时撤离，失败只丢当前轮未入箱收益。当前存档schema为v3，启动时会迁移v1及缺字段旧档。

阶段5增量以纯程序化低多边形卡通鱼市为视觉方向：五岛色板及水面/雾/天气/甲板规则集中在领域配置，22种鱼与3个Boss采用独立轮廓参数和状态标志；外观只改变船、鱼箱与命中特效，不提供周挑战数值权益。短音效由 Web Audio 合成，不含第三方或AI音频文件。资源登记见 `THIRD_PARTY_ASSETS.md`，商店实拍规格见 `docs/STORE_ASSET_CHECKLIST.md`。

当前仓库未提供真实运行截图，未进行成品视觉人工验收。Web `<20 MiB` 首载预算只有在构建目录存在时才由平台预检实测；未构建不得宣称达标。
