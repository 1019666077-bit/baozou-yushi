# 潮退浮站 · 世界优先里程碑

进港要一眼读出：**水淹到天边，脚下是还浮着的小站。**
不是灰码头，也不是开放世界。钓鱼手感（甩 / 拽 / 扑 / 入箱）已经能玩；先把「家」做成洪水退潮后的浮岛渔站，经济先冻。

## 品类锚点（只写内部）

同品类观感：淹没地平线 + 漂浮作业站。
玩家可见文案只用原创中文：潮退浮站、浮岛小站、订单板、浮台升级、修建中。
禁止竞品名，禁止搬素材。

## 冻结（各刀都守）

- 经济 **11/90** 不动。
- 不做英雄、联盟、开放世界、挂机。
- 主橙 CTA 只属于 **出海 / 开始教学 / 再出海**，不让订单或浮台抢走。

- 官方路径：`Boot.scene` → `RuntimeHome` → `RuntimePrototype`。
- 甩钩、拽鱼、甲板扑腾、入箱。
- 教学关 + 卖出；竿 2 级 90，首售约 11，主目标写还差、再出海能补。
- 教学完成前锁升级 / 图鉴 / 榜。

目标：港看起来像潮退后的浮岛渔站。

已落地：

- `HarborStage` / `ProcGeom`：远层半沉楼影、淹没天际、浮木；中层木甲板、浮筒、鱼箱、简易市集棚。
- `GrayArt` / `ArtRecipe` 回退同一套远中层（无 Creator 时也能读出洪水浮站）。
- `RuntimeHome`：标题「潮退浮站 · 浮岛小站」；**订单板**、**浮台升级**点开「修建中」面板，不接经济。
- 第一局体验代理同步标题与占位钮；主橙 CTA 仍是出海系。

未做（故意）：真订单履约、浮台等级数值、漂物玩法、Prototype 手感重调。
