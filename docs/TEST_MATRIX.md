# 真机与回归矩阵

## 设备

- 低端安卓：4GB内存、较低GPU，目标30FPS。
- 中端安卓：6–8GB内存，目标45FPS以上。
- 旧iPhone：iPhone 8/X级别，重点查内存和Canvas文本。
- 新iPhone：近三代机型，检查高性能模式和刘海安全区。

## 每台设备必测

- 首次冷启动、二次热启动、清缓存后启动。
- 教学完整流程、三岛各一局、Boss三阶段。
- 切后台30秒/5分钟、锁屏、来电中断、恢复倒计时。
- Wi-Fi切移动网、断网进入、战斗中断网、恢复联网后云存档同步。
- 本地档高revision、云档高revision、相同revision不同时戳。
- 分包未下载、下载中断、存储空间不足。
- 连续玩10局，记录首局和第10局内存差。
- 音效、震动、低配模式、静音键、安全区和触摸边缘。

## 性能红线

- 主包≤4MiB；总包≤20MiB。
- 首次可交互≤5秒。
- 同屏活跃鱼≤12、弹道≤24。
- 中端安卓P95帧耗时≤22ms。
- 10局后内存不得持续单调增长；退出岛屿后纹理和音频可释放。
