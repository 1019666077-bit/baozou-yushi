# 商店素材拍摄清单（DRAFT）

> 本文仅定义可执行规格与拍摄方案，不是成品截图。所有占位模板必须带 `DRAFT` 水印且不得进入 release。当前没有真实运行截图，也未完成人工视觉验收。

## 输出规格

- 横版封面：1920×1080，PNG/JPEG，主体与标题位于中央 80% 安全区。
- 竖版封面：1080×1920，PNG/JPEG，保留顶部/底部各 180 px 平台裁切区。
- 横版截图：1920×1080，至少 5 张；不得拉伸或拼接伪造玩法。
- 移动截图：实际目标设备原生分辨率；保留刘海、圆角与手势区。
- 单张建议小于 2 MiB；导出后检查文字、价格、评级图标及弱点标志可读性。

## 必拍镜头

1. 泡沫湾首局：等级、实时估价、新鲜度、目标四项主 HUD 同屏，无遮挡。
2. 弱点击破：弱点标志、命中特效和行为状态提示同时可读。
3. S级捕获：鱼的完整轮廓、S级反馈、鱼箱入箱动作。
4. Boss预警：Boss独特轮廓、预警状态和甲板环境，不剧透结算。
5. 鱼市出售：木牌/价格签层次、单鱼估价与总收益。
6. 五岛对照：真实运行中分别拍摄水面、雾/天气与甲板规则。
7. 外观商品：仅用已购买账号拍船漆、鱼箱和命中特效的实际应用。

每个镜头记录：构建号、平台、设备、分辨率、画质档、拍摄人、日期、是否裁切。禁止把编辑器预览、概念图或带 `DRAFT` 的模板冒充运行截图。

## 封面构图建议

- 前景：船与一条Boss形成对角动势；Boss轮廓不得被标题遮挡。
- 中景：鱼箱与价格签体现“捕获变现”，不展示虚假折扣或未开放功能。
- 背景：选一座岛的协调色板，避免把五岛天气混成不存在的场景。
- 标题区保持高对比；四角预留渠道徽标与年龄提示位。

## 验收

- [ ] 16:9浏览器与至少一台刘海/圆角移动设备实拍。
- [ ] 画面内容可从对应构建复现。
- [ ] 无 DRAFT 水印、调试面板、个人信息或平台测试账号。
- [ ] 未拥有外观不可选择；周挑战画面无广告/付费数值加成。
- [ ] 素材来源已在 `THIRD_PARTY_ASSETS.md` 登记。
- [ ] 人工检查完成；在完成前不得写“已验收”。
