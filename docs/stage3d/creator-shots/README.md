## 怎么拍

1. 本机 Cocos Creator **3.8.8** 打开本仓库**根目录**（不要打开 `assets/` 子文件夹）。
2. 资源管理器打开 `assets/scenes/Boot.scene`。
3. 预览：工具栏 ▶，或 Windows `Ctrl+P` / macOS `Cmd+P`。应进入港口（RuntimeHome）。装配见 `docs/SCENE_SETUP.md`。
4. 按下面 4 个**文件名原样**截 png，丢进本目录。也可以从本机 `build/web-desktop/` 浏览器预览里截，文件名必须一样。
5. 打印同一份清单：`npm run shots:list`（或 `node tools/stage3d-shot-checklist.mjs`）。

当前进度以清单脚本为准：**0/4**（未伪造 png）。
