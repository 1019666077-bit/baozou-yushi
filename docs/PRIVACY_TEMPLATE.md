# 隐私政策模板

> 正式发布前必须由发行主体和法律顾问按实际SDK、主体信息与服务器地区复核，删除本提示。

本游戏为提供登录、云存档、好友排行榜、故障诊断和运营分析，会处理微信OpenID、游戏进度、设备性能等级、局内行为事件和错误日志。我们不读取通讯录、精确位置、相册或麦克风，不提供玩家聊天和UGC上传。**当前未接入广告 SDK**，不得把广告收集写进正式政策。

## 用途

- OpenID：区分账号、隔离云存档和排行榜数据。
- 游戏进度：本机存储 + 云函数 `saveGame` / `loadSave` 跨设备恢复。
- 设备性能等级：自动选择低配模式。
- 行为事件：经 `reportEvents` 分析教学和关卡体验，不用于广告画像。
- 错误日志：定位崩溃和网络故障。
- 好友榜：经 `submitScore` 校验后的精彩分；开放数据域仅对互为好友可见。

## 保存与删除

云存档在账号使用期间保存；分析明细计划保存30天后聚合或删除。玩家可在设置页删除存档：客户端清本机后调用 `deleteSave`，服务端按OpenID删除`player_saves`，并尽量删除`leaderboard`和未聚合日志。
