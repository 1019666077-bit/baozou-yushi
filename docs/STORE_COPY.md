# 商店素材文案

## 名称

暂名：暴走鱼市

正式提交前进行商标和同名小游戏检索。

## 一句话

抛竿锁鱼、花式收服：动作越精彩，鱼市售价越高。

## 简介

你是海边鱼市的新任潮汐收货员。驾驶小艇前往泡沫湾、棱光礁与风眼环礁，用弹力鱼竿、泡泡连发炮和磁力蓄能叉收服奇特海鱼。击中弱点、空中命中、连续命中与完美收杆都会提高精彩倍率，让同一条鱼卖出完全不同的价格。升级工具、补全图鉴，最后挑战会操纵声浪与旋涡的潮鸣巨鲲。

## 截图规划

1. 首次抛竿锁定湾鳍鱼。
2. 弱点击破，精彩倍率从1.0跳到1.4。
3. 跃礁鱼腾空，玩家空中命中。
4. 港口结算，展示价格拆分。
5. 潮鸣巨鲲与双旋涡首领阶段。

## 15秒视频

- 0–3秒：抛竿，鱼跃出水面。
- 3–8秒：弱点、空中、连击三个快速反馈。
- 8–11秒：同一条鱼价格从43涨到112。
- 11–15秒：巨鲲登场，字幕“打得越漂亮，卖得越贵”。
