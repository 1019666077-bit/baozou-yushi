# 产品规格

## 产品定位

横屏动作物理钓鱼，单局3–5分钟，单人闯关加好友异步排行。鱼是会扑腾的刚体：拽上岸、砸晕、搬进鱼箱。核心体验是“打得越漂亮，卖得越贵”。不是《渔力全开》移植，岛、鱼、名字和造型全部原创。

## 核心体验

1. 抛竿把海里的鱼拽上甲板。
2. 鱼在甲板上弹跳、打转，会试图跳回海里。
3. 用鱼炮或鱼叉砸它；命中只出星星和泡泡，没有血液或伤口。
4. 弱点、浮空砸、连击抬高精彩度；砸晕后捡起，搬进左边鱼箱才算入箱。
5. 精彩度形成1.0–3.0倍价格倍率。回港出售，升级工具，解锁下一座岛。

## 操作

主要交互带在**下半屏**（设计坐标 y≤0），上半留给海面/岛。

- 左下半屏拖动：在甲板上小范围移动。
- 右下半屏拖动：瞄准；松手：发射。
- 抛竿：锁最近的鱼并往甲板上拽。
- 捡起：扛起砸晕的鱼，**下半屏拖到左边鱼箱**再松手。碰到鱼箱吸入；松在海里会跑；松在甲板则掉下再捡。
- 鱼砸上甲板后有质量/摩擦/短滑移；未及时处理会滑/跳回水。
- 空中有可砸窗口，接近顶点是完美窗口（高光）。
- 暂停：保存当前局摘要，恢复时倒计时3秒。

## 新手流程

教学关默认开启。新玩家未完成 `tutorialComplete` 时进入练潮码头（`island_tutorial`），只开放基础鱼竿；完成首次弱点击破并入箱后，才进入泡沫湾等正常岛。教学完成前，港口升级/图鉴/榜按 `TutorialFlow.harborUnlocks` 锁定。

## 成功指标

- 首次入箱中位时长≤60秒。
- 三局到达率≥40%。
- 60%以上测试者能复述“空中砸、打得漂亮鱼更值钱”。
- 中端安卓战斗帧率≥45FPS；P95单帧≤22ms。

## 非目标

MVP不做实时联机、开放航海、成品网格角色、付费抽卡、聊天、公会、老虎机和强制插屏。微信首版用透视方块甲板接现有扑腾，不上 Ammo。
