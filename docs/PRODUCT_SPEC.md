# 产品规格

## 产品定位

横屏动作物理钓鱼，单局3–5分钟，单人闯关加好友异步排行。鱼是会扑腾的刚体：拽上岸、砸晕、搬进鱼箱。核心体验是“打得越漂亮，卖得越贵”。不是《渔力全开》移植，岛、鱼、名字和造型全部原创。

## 核心体验

1. 抛竿把海里的鱼拽上甲板。
2. 鱼在甲板上弹跳、打转，会试图跳回海里。
3. 用鱼炮或鱼叉砸它；命中只出星星和泡泡，没有血液或伤口。
4. 弱点、浮空砸、连击抬高精彩度；砸晕后捡起，搬进左边鱼箱才算入箱。
5. 鱼上甲板后鲜度从1.2逐步降至0.5；拖延会同时损失售价并增加跳海逃跑风险。
6. 精彩度形成1.0–3.0倍价格倍率。回港出售，升级工具，解锁下一座岛。

## 操作

主要交互带在**下半屏**（设计坐标 y≤0），上半留给海面/岛。

- 左下半屏拖动：在甲板上小范围移动。
- 右下半屏拖动：瞄准；松手：发射。
- 抛竿：锁最近的鱼并往甲板上拽。
- 捡起：扛起砸晕的鱼，**下半屏拖到左边鱼箱**再松手。碰到鱼箱吸入；松在海里会跑；松在甲板则掉下再捡。
- 鱼砸上甲板后有质量/摩擦/短滑移；未及时处理会滑/跳回水。
- 空中有可砸窗口，接近顶点是完美窗口（高光）。
- 暂停：保存当前局摘要，恢复时倒计时3秒。

## 新手流程

教学关默认开启。新玩家未完成 `tutorialComplete` 时进入练潮码头（`island_tutorial`），只开放基础鱼竿；完成首次弱点击破并入箱后，才进入泡沫湾等正常岛。教学完成前，港口升级、图鉴和榜按 `TutorialFlow.harborUnlocks` 锁定。卖完教学鱼约11金，鱼竿2级90金；买不起升级时主按钮仍是再次出海。

风眼环礁由130秒双潮加90秒首领战组成，目标总局长约3分40秒，保持在3–5分钟范围内。

## 阶段2循环

- `PlayerSave v2`保存鱼类熟练度、捕获次数、最佳等级、每日/周挑战进度和无尽记录；所有旧档经单一迁移函数补齐。
- 港口每日生成3个稳定短目标，覆盖空中捕获、A级以上、指定工具或岛屿；目标约15分钟完成，只奖金币或外观碎片且不可重复领取。明显回拨本地时钟不会刷新订单。
- 周挑战以ISO周键和固定种子生成统一岛屿、鱼池、工具与180秒规则。本阶段保存本地周分、最好成绩和上榜资格，不依赖微信好友榜；任何付费/广告加成都使该周尝试不可提交。
- 击败任意Boss解锁无尽潮。每180秒一轮，韧性、速度和刷新频率受上限约束线性增长；过轮收益入箱，主动撤离保留当前收益，失败仅清除当前轮未入箱收益。
- 港口目标页提供每日、周挑战与无尽入口；图鉴每页最多12条，显示熟练度、捕获次数和最佳等级。

## 内容与经济

基础内容为泡沫湾、棱光礁、风眼环礁、雾钟群岛、熔潮火山，共22鱼、3 Boss。工具保持3类并扩至5级；L4/L5以弱点半径、鲜度保底、破甲、空中窗口和蓄能速度形成横向能力，不售卖战力奖励。自动模拟目标为五岛基础解锁中位180–300分钟、每日目标15分钟可推进、无尽第20轮单位收益不超过首轮1.76倍。

## 成功指标

- 首次入箱中位时长≤60秒。
- 三局到达率≥40%。
- 60%以上测试者能复述“空中砸、打得漂亮鱼更值钱”。
- 中端安卓战斗帧率≥45FPS；P95单帧≤22ms。

## 非目标

MVP不做实时联机、开放航海、成品网格角色、付费抽卡、聊天、公会、老虎机和强制插屏。微信首版用透视方块甲板接现有扑腾，不上 Ammo。
