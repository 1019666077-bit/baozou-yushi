# 内容与首轮进度

## 世界观

玩家是新任“潮汐收货员”，驾驶小艇为港口鱼市补货。海鱼会用泡泡、甲壳和水流抵抗捕捞；所有工具只削减“韧性”，成功后鱼进入透明水箱，不出现伤害。

## 首轮30–45分钟

- 0–2分钟：新玩家默认开启练潮码头教学，捕获湾鳍鱼，理解弱点和精彩倍率。教学完成前不能自由出航泡沫湾。
- 2–10分钟：泡沫湾两局，先买鱼竿2级，再解锁泡泡连发炮；棱帆鱼是首次精英挑战。
- 10–22分钟：支付240金币解锁棱光礁。银绸鱼训练预判，灯豆鱼训练目标切换，铁颌团鱼训练找甲壳开口。
- 22–34分钟：支付680金币解锁风眼环礁。暖流鳗训练追踪，跃礁鱼训练空中命中，旋潮鳐训练连续击破分身。
- 34–45分钟：潮鸣巨鲲三阶段首领。通关后开放周榜、全图鉴目标和工具3级升级。

## 鱼类职责

- 湾鳍鱼：慢速、弱点大，新手教学。
- 贝甲鱼：正面减伤，转身露出贝壳缝。
- 银绸鱼：直线高速冲刺，训练预瞄。
- 灯豆鱼：分出两个无价值泡泡影，训练辨识。
- 暖流鳗：曲线高速移动，蓄能叉克制。
- 跃礁鱼：周期跃出水面，稳定产出空中精彩动作。
- 棱帆鱼：冲刺后长硬直，第一只精英。
- 铁颌团鱼：护甲循环开合，连发炮克制。
- 旋潮鳐：生成分身，真身弱点颜色保持不变。
- 潮鸣巨鲲：声浪、旋涡、环场冲刺三阶段终局首领。

## 首领节奏

第一阶段每4.5秒发直线声浪，教玩家横移；第二阶段双旋涡限制站位但鳍部弱点更大；第三阶段连续冲刺，躲过后提供5秒输出窗。90秒内结束，失败保留本局普通鱼收益。

## 经济控制

- 第一局目标收入70–100金币，保证一次鱼竿升级。
- 泡沫湾两局累计240–330金币，能解锁棱光礁。
- 棱光礁3–4局累计680–900金币，能解锁风眼环礁。
- 普通操作与高精彩操作首轮总收益差控制在1.5–2倍。
- 解锁费用不与工具升级形成硬卡：任一阶段最多需要额外重复1局。
