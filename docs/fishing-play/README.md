# 手机上直接玩的钓鱼预览

这是 three.js 打出来的静态页，不是 Cocos Creator 实机。不需要服务器。

## 怎么打开

1. 拿到仓库后，用手机或电脑浏览器打开 `docs/fishing-play/index.html`。
2. 脚本、样式、音效都是相对路径（`app.js`、`hud.css`、`audio/*.mp3`），用文件管理器打开即可。
3. 若浏览器拦截 `file://` 下的脚本，把 `docs/fishing-play/` 放到任意静态站点。若仓库开启 GitHub Pages 并指向 `docs/`，地址是 `.../fishing-play/`。本仓库不改 Pages 设置。

触屏：底部按住蓄力、松手抛竿、浮标落水后才开始等咬、拉下去再提、按住收线。沙滩和码头上，左侧圆钮可以挪大约 6.5 米。左右滑动大约能偏转 25°。屏幕中间有准星。点小地图上的点可以去码头、上船，或打开乔和玛塔。乔在 (49.9, -74.6)、半径 3.2 米，玛塔在 (85.5, -60.5)、半径 3.0 米，走进这个半径才出现「交谈」。这几步走不到摊位，打开他们仍用小地图。左下角「换钓点」在沙滩、码头、船之间换。鱼舱里可以放生。左上角「再看引导」把钓鱼引导再播一遍，不解锁港口教学。时段不会自己跳，要用调试条里的清晨、白天、黄昏、夜晚来换；默认是 16.2 点，天色按这个钟点，不自动跳到下一档。地址加上 `?debug=1` 才显示水域、时段、乔、玛塔、鱼舱、拿出鱼竿、收回那一排。第一页是引导，第二页是手机上的抛、提、收。点「跳过」或「下一步」。

重新打包（改了 `tools/fishing-preview/play.ts` 之后）：

```bash
node tools/fishing-preview/build-static.mjs
```
