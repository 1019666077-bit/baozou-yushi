# 出海钓鱼预览画面

这些图来自 `docs/fishing-play/` 的无头 Chrome 实跑（three.js），不是手绘，也不是 Cocos Creator 实机。录的时候地址不带 `?debug=1`，顶部调试按钮不出现。

- `01-idle.png` 码头待机：细竿从右下斜向水面，鱼线垂到水里的红白浮标
- `02-cast.png` 蓄力抛竿
- `02-wait.png` 等咬：浮标在水面上，带着水花
- `03-fight.png` 拉力对抗，竿身弯曲，鱼线仍接到水里的浮标
- `04-card.png` 全屏渔获卡
- `05-stall.png` 乔的鱼摊
- `05-shop.png` 玛塔的渔具店（1280×720）
- `06-shop-375.png` 同一家店在 375×667，滚到最底，船灯和「离开」都在画面里
- `07-phone.png` 横屏手机 896×414（项目是横屏）
- `loop.gif` 同一套规则走完的一段，不超过 15 秒

375×667、414×896、896×414 都量过：看得见的文字框和按钮两两不相交，并且在视口里。商店、鱼摊、渔获卡打开时，底部提示、小地图和大操作按钮会藏起来。重叠检查写在 `tools/fishing-preview/record.mjs`。
