# 出海钓鱼预览画面

这些图来自 `docs/fishing-play/` 的无头 Chrome 实跑（three.js），不是手绘，也不是 Cocos Creator 实机。录的时候地址不带 `?debug=1`，顶部调试按钮不出现。竿在画面右下，竿尖不过中线；鱼线是细抛物线，接在变换后的竿尖上。默认黄昏海面是暖蓝色，带一点橙色反光。

- `01-idle.png` 码头待机：原版持竿姿态，没有浮标
- `01-idle-375.png` 同一待机，375×667 手机竖屏
- `02-cast.png` 蓄力抛竿
- `02-fly.png` 浮标还在飞
- `02-wait.png` 等咬：浮标落在水面上
- `03-fight.png` 拉力对抗，竿身弯在画面右下，线被拉直
- `03-fight-375.png` 同一段对抗，375×667 手机竖屏
- `04-card.png` 渔获卡，带 9 秒进度条
- `05-stall.png` 乔的鱼摊
- `05-shop.png` 玛塔的渔具店（1280×720）
- `06-shop-375.png` 同一家店在 375×667，滚到最底，船灯和「离开」都在画面里
- `07-phone.png` 横屏手机 896×414（项目是横屏）
- `08-dawn.png` `08-day.png` `08-dusk.png` `08-night.png` 四个时段的天空和光
- `09-finder.png` 船上的探鱼器（水深和鱼讯）和夜里的甲板灯
- `loop.gif` 同一套规则走完的一段，不超过 15 秒

待机、对抗、渔获卡、商店四个场景，各在 375×667、414×896、768×1024 量过：看得见的文字框、按钮和面板两两不相交，并且在视口里。对抗和渔获卡会藏起「和乔交谈」「和玛塔交谈」和小地图，拉力条在左上，不压竿。渔获卡弹出时浮标收起，鱼线一起收起。检查在 `tools/fishing-preview/hud-overlap.mjs`，`npm run validate` 会跑它。
