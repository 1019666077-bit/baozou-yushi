# 合规与知识产权清单

## 原创边界

- 不使用《渔力全开》及其英文名、Logo、角色、岛屿、鱼类造型、任务、台词、UI、音效、数值和宣传素材。
- 仅使用不可垄断的抽象玩法思想：捕获、技巧评价、售价倍率、装备成长。
- 所有外购素材登记来源、许可证、订单号和允许的发行平台。

## 内容表达

- “击杀”统一改为“收服/捕获”，“血量”统一改为“韧性”。
- 武器采用卡通鱼炮、泡泡弹、磁力鱼叉；命中只产生星星、泡泡和眩晕反馈。
- 无血液、伤口、肢解、虐待动作和真实动物痛苦音效。
- 不设置老虎机、轮盘、押注、竞猜和付费随机抽取。
- 鱼市行情为公开、确定性轮换，玩家操作前可以看到结果。
- 不用“分享后复活/领奖”等诱导分享设计。

## 上线材料

- 启动画面预留游戏批准文号、著作权登记号与健康游戏忠告位置。
- 提供隐私政策、儿童隐私说明、账号注销和数据删除入口。
- 若未来加入昵称、头像、聊天或玩家图片，展示前必须经过微信游戏内容安全接口。
- 广告不得遮挡操作区，不得在捕获中途强制打断。

## 审核前逐项确认

- [ ] 商标与名称检索无明显冲突
- [ ] 软件著作权材料齐全
- [ ] 版号/备案与发行主体路径已确认
- [ ] 所有素材授权可追溯
- [ ] 无写实动物伤害
- [ ] 无赌博或有价随机机制
- [ ] 无诱导分享
- [ ] 隐私政策与实际SDK一致
